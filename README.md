# Dad Joke Showdown

One dad joke, at most 200 characters, written to be told out loud. Run the builder:

```sh
python main.py
```

It verifies `entry.txt` against the gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
